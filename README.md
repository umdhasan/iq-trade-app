# TradePro IQ

IQ Option-এর জন্য Kotlin + Jetpack Compose অ্যাপ: রিয়েল মার্কেট প্রাইস, ৪টি মার্কেট লিস্ট (Digital, Binary, Forex/Margin CFD, Blitz), Hasan Pro Signal ইন্ডিকেটর, IQ Option ওয়েব টার্মিনাল ও ডেমো ট্রেড (কাউন্টডাউন + Win/Loss)।

## কীভাবে কাজ করে
- **প্রাইস:** ক্রিপ্টো Binance থেকে, ফরেক্স/ইনডেক্স/কমোডিটি/স্টক Yahoo Finance থেকে। সব দাম আসল মার্কেট থেকে আসে, কোনো নকল দাম নেই।
- **OTC অ্যাসেট:** IQ Option নিজে OTC দাম বানায়, তাই এগুলোতে আসল আন্ডারলাইং দাম রেফারেন্স হিসেবে দেখানো হয়।
- **IQ Option-এর নিজস্ব বাস্কেট** (যেমন Euro Index): পাবলিক ফিড নেই, তাই "পাবলিক ফিড নেই" দেখায়।
- **Hasan Pro Signal:** WMA(2), EMA(21), RSI(21) ও শক্তিশালী ক্যান্ডেল শর্ত (UP+, DOWN+, UP?, DOWN?)। সিগন্যাল ক্লোজ হওয়া ক্যান্ডেল থেকে নেওয়া হয়। "সেটআপ স্ট্রেংথ" নিয়ম মেলার স্কোর, জেতার সম্ভাবনা নয়।
- **ট্রেড:** অ্যাপের ডেমো ট্রেড সিমুলেশন। IQ Option-এর অফিসিয়াল পাবলিক API নেই, তাই আসল ট্রেড ইউজার নিজে ওয়েব টার্মিনালে করবেন।

## সীমাবদ্ধতা
- Yahoo Finance-এর endpoint আনঅফিশিয়াল, রেট-লিমিট বা ফরম্যাট বদলাতে পারে। ইঞ্জিনে ব্যাকঅফ আছে।
- Digital মার্কেটের লিস্ট অনুমানভিত্তিক, IQ Option-এর পুরো লিস্টের সাথে হুবহু নাও মিলতে পারে।
- এই কোড এখনও কম্পাইল করে চালিয়ে টেস্ট করা হয়নি। প্রথম বিল্ডে ত্রুটি এলে লগ পাঠান।
- এটি ট্রেডিং পরামর্শ নয়। কোনো সিগন্যাল বা স্ক্রিপ্ট জেতার নিশ্চয়তা দেয় না।

## APK বানানো (GitHub Actions)
1. এই ফোল্ডারের সব ফাইল একটি GitHub রিপোজিটরিতে push করুন (`gradle/wrapper/gradle-wrapper.jar` সহ)।
2. **Actions** ট্যাবে "Build debug APK" চালু হবে (বা **Run workflow** চাপুন)।
3. শেষ হলে রান পেজের **Artifacts** থেকে `TradePro-IQ-debug-apk` নামিয়ে APK ইনস্টল করুন।

## লোকালি চালানো
Android Studio-তে প্রজেক্ট খুলে `./gradlew assembleDebug` চালান। JDK 17 লাগবে।
